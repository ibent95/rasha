# web-crm-angular — RASHA CRM Website

Customer Relationship Management frontend.

## Structure

```
websites/web-crm-angular/
├── src/
├── Dockerfile
├── package.json
├── angular.json
└── tsconfig.json
```

## Development

1. Scaffold an Angular app in this directory
2. Add a Dockerfile (extend rasha-node-base or use any base)
3. Add to docker-compose.yml and docker-bake.hcl
4. Connect to svc-crm-laravel via API proxy
